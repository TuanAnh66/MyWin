# Sources and scope

MyWin archives the custom orchestration scripts and build records created during a personal Windows image experiment. The workflow was developed using [ntdevlabs/tiny11builder](https://github.com/ntdevlabs/tiny11builder), checkout `38f7ab6` (`winui-preview`).

The upstream GUI, upstream PowerShell builders, upstream Git history and upstream screenshots are not copied into this repository. Obtain them from the original repository and observe their own notices and applicable permissions.

Windows media, registry hives, Microsoft binaries, wimlib/7-Zip/offreg binaries, VirtIO packages and third-party installers are not distributed here. Names, package inventories, content hashes and reports describe the local experiment; they do not grant a license to the referenced software.

No license is asserted over upstream material or Microsoft/third-party components. This repository does not include product keys or activation tools.
